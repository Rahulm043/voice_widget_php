# TryAutomate Voice Widget

A minimal, portable voice assistant for PHP/Laravel sites.

## 📁 Essential Files
- `voice-assistant.js`: Logic and audio handling.
- `voice-assistant.blade.php`: Laravel UI component.
- `HANDOVER_GUIDE.md`: 3-step integration instructions.

## 🧪 Testing Locally
1. Add `GEMINI_API_KEY` to a `.env` file.
2. Run `npm install` and `npm start`.
3. Open `http://localhost:8000`.
